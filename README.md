# Засоби вимірювання: матеріали для експертних груп

Слайди з анімаціями і теорія для шести експертних груп у кожній з двох **окремих** тем. Сайт відкривається через GitHub Pages: `index.html` — сторінка вибору теми.

| Тема | Сторінка | Теорія для груп (PDF) | Розділ підручника |
|---|---|---|---|
| 2.5. Вимірювання температури | `temperatura.html` | `teoriya-temperatura/grupa-1…6.pdf` | [2.5](https://pupenasan.github.io/avpbook/2_5.html) |
| 2.6. Витратоміри | `vytratomiry.html` | `teoriya/grupa-1…6.pdf` | [2.6](https://pupenasan.github.io/avpbook/2_6.html) |

Старі посилання на кшталт `index.html#g3` автоматично відкривають тему 2.6 «Витратоміри».

## Групи теми 2.5

1. Класифікація і скляні термометри (п. 2.5.1, 2.5.2)
2. Біметалеві та дилатометричні термометри (п. 2.5.2)
3. Манометричні термометри (п. 2.5.2)
4. Термоелектричні термометри (п. 2.5.3)
5. Термоперетворювачі опору (п. 2.5.4)
6. Пірометри випромінювання (п. 2.5.5)
